## Data/model distinction and local baseline

The pages provide hosted inference IDs and metrics, not a verified local checkpoint download. Vasudevs exposes hosted model v7 (YOLO26, with checkpoint label v6) and reports mAP@50 84.7%, precision 86.7%, recall 78.3%; EmmaSheppard exposes hosted model 26 (Roboflow 3.0) and reports 87.1%, 83.1%, and 83.7%. These are project-reported hosted metrics across multi-class tasks, not comparable adult-only measurements on this repository's held-out test set. The project CC BY dataset license is not evidence that model weights are downloadable or licensed identically. Do not use these values as the local baseline. A locally reusable lanternfly checkpoint has not been verified.

Recommended approach: keep the current YOLOv8n/Flask path, use the adult-only COCO export, and fine-tune the official generic YOLOv8n initialization. If a lanternfly checkpoint becomes locally downloadable, first establish its architecture, exact checkpoint provenance, and separate weight license; a YOLO26/Roboflow 3.0 checkpoint cannot be assumed to load as a YOLOv8 model. Compare any compatible and legally reusable checkpoint in a separate candidate run on the same train/validation and held-out test data. Ultralytics states that its code, pretrained models, and resulting trained models are AGPL-3.0 by default; private or commercial deployment without open-sourcing the relevant project may require an Enterprise License. Review [Ultralytics licensing](https://www.ultralytics.com/license) before distributing or deploying beyond academic open-source use. The dataset CC BY 4.0 attribution does not grant rights to Roboflow hosted model weights.

## Supplied v7 ZIP findings

The archive is 504,401,817 bytes compressed and 504,931,908 bytes uncompressed. It contains 2,427 train, 679 validation, and 343 test images; source classes are `Adult Spotted Lanternfly`, `Early Nymph Spotted Lanternfly`, `Late Nymph Spotted Lanternfly`, `SLF egg`, and an unused `objects-I8a4-xHgv` category. Source adult box counts are 3,292/1,072/774 by split. The adult-only conversion retained 3,275/1,062/772 valid boxes. It excludes all nymph/egg/other classes from detector labels. The source export has 15 train images with no annotations; 517 train, 139 validation, and 65 test images lack an adult box. Those 721 empty adult-only labels remain pending, not verified negatives.

Review flagged 29 malformed/out-of-bounds adult annotations affecting 25 images. Four image files have raw pixel dimensions transposed relative to their COCO dimensions; they were rotated counter-clockwise to match the recorded COCO box space, with those images held for visual review. The source has 0 exact decoded-pixel duplicates after orientation normalization. Combined aHash/dHash screening (both distances <=2) found 198 likely near-duplicate pairs across splits: 112 train/validation, 64 train/test, and 22 validation/test, affecting 317 image rows. These pairs require review; retain the original split design and remove duplicate copies from train/validation when they overlap test. Contact sheets and the full pair/annotation records live in ignored `data/external/roboflow/vasudevs_v7_review/`.

The imported YOLO staging dataset passes structural validation with 2,427/679/343 images and 3,275/1,062/772 adult boxes. That PASS only covers file/label structure and box geometry after invalid adult records were omitted. It does **not** mean labels or empty-label negatives have been human verified. The candidate workflow therefore excludes all empty-label examples and labels the remaining set as machine-screened, not human verified. Source test history is unknown, so its final results remain exploratory.

## Import workflow and safeguards

The import helper consumes a Roboflow COCO ZIP and writes under ignored `data/external/roboflow/`. It selects one exact adult category, maps it to YOLO class 0, stores images and labels outside application code, preserves original COCO JSON and export READMEs, hashes decoded pixels to remove exact duplicates, records source URL/version/license/split/category mapping, and creates a review CSV. Every image starts pending; rows containing malformed annotations or likely cross-split duplicates are explicitly flagged. Images with no adult boxes remain unverified negative candidates. `scripts/screen_roboflow_adults.py` creates a derivative screen that keeps one item per near-duplicate connected component (test first, then train, then validation), excludes the other copies without changing split assignments, excludes all empty-label candidates, and excludes all annotation/orientation-flagged rows. Retained boxes pass structural checks but are not individually human verified. `scripts/build_roboflow_candidate.py --source-adult-screening` records that distinction. Candidate validation checks for exact leakage; the builder also rechecks near-duplicate hashes.

```powershell
python scripts/import_roboflow_coco.py --zip "C:\Users\mglas\Downloads\Spotted Lanternfly Annotated Set All Boxes No Null.v7i.coco.zip" --output data\external\roboflow\vasudevs_v7_review --version spotted-lanternfly-annotated-set-all-boxes-no-null-nbpge-70ujp/7 --source-url https://universe.roboflow.com/vasudevs-workspace-tjnq3/spotted-lanternfly-annotated-set-all-boxes-no-null-nbpge-70ujp --license "CC BY 4.0" --attribution "Vasudevs Workspace; Spotted Lanternfly Annotated Set All Boxes No Null, Roboflow Universe; CC BY 4.0" --adult-class "Adult Spotted Lanternfly"
```

The ZIP importer uses a temporary copy under `data/` and cleans it after import; the source archive remains untouched. The output staging set is ignored by Git. A Roboflow API key is not needed to rerun the importer against this ZIP.
